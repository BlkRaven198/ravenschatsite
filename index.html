Ravens|Chat

Мультичат для стримов: YouTube, Twitch и VK Live в одном окне

Ravens|Chat — настольное приложение для Windows, созданное для стримеров. Его цель — объединить сообщения чатов трансляций YouTube, Twitch и VK Live (Live.VKvideo.RU) в одной удобной ленте, чтобы автор трансляции могла читать все сообщения зрителей и отвечать на них, не переключаясь между вкладками и устройствами.

Политика конфиденциальности

Что делает приложение

  • Единая лента чатов — сообщения со всех подключённых платформ отображаются в одном окне в реальном времени.
  • Отправка сообщений — ответы в чаты платформ прямо из приложения.
  • Модерация — удаление сообщения, тайм-аут, бан и разбан на подключённых каналах.
  • OBS-виджет — отдельный оформляемый виджет чата для показа поверх трансляции в OBS Studio.
  • Прокси — опциональная работа через SOCKS5-прокси для обхода сетевых ограничений.

Как приложение работает с данными

Только официальные API

Ravens|Chat обращается исключительно к официальным API платформ (YouTube Data API от Google, API Twitch, API VK). Все данные хранятся локально на вашем компьютере; у приложения нет собственных серверов, рекламы и трекеров.

Соответствие требованиям Google

Приложение использует API Google только по назначению — для отображения и отправки сообщений чата YouTube, и соблюдает Условия предоставления API Google и Политику конфиденциальности Google. Приложение не использует API Google для создания или распространения несогласованных интимных изображений (AI NCII), не создаёт профилей пользователей, не собирает данные для рекламы и не продаёт данные третьим лицам.

Политика конфиденциальности

Полный перечень собираемых данных, порядок их использования, хранения и удаления описан в Политике конфиденциальности Ravens|Chat.
