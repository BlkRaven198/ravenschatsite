Политика конфиденциальности

Главная · Последнее обновление: 7 октября 2026 г.

1.Общие положения

Настоящая Политика конфиденциальности описывает, как приложение Ravens|Chat (далее — «Приложение») собирает, использует, хранит и защищает информацию. Приложение — настольная программа для Windows, объединяющая чаты платформ YouTube, Twitch и VK Live (Live.VKvideo.RU), а также OBS-виджет для трансляций. С приложением можно ознакомиться на главной странице.

Используя Приложение, вы подтверждаете, что ознакомились с этой Политикой и согласны с описанными в ней порядком работы с данными.

Контакт по вопросам конфиденциальности: Goddamn-Ravens@yandex.ru.

2.Какие данные собираются

Приложение запрашивает и хранит только те данные, без которых его функции невозможны.

Токены доступа (OAuth)

Для отправки сообщений и модерации Приложение получает от платформ токены доступа к вашим аккаунтам YouTube (Google), Twitch и VK Live. Пароли аккаунтов Приложению не передаются, не запрашиваются и не хранятся. Авторизация выполняется через официальные протоколы OAuth на страницах самих платформ. Отозвать доступ можно в любой момент кнопкой «Выйти» в настройках Приложения или в настройках соответствующего аккаунта.

Идентификаторы каналов

Ссылки и логины подключаемых каналов: адрес трансляции или канала YouTube, логин Twitch-канала, логин блога VK Live — только для подключения чата к нужному каналу.

Настройки оформления

Выбранные цвета, шрифты, изображения фона, параметры виджета и прочие настройки отображения.

Служебные данные

Счётчики квоты запросов к API (чтобы Приложение могло предупредить о лимитах), самостоятельно загруженные вами шрифты и изображения для виджета, записи журнала работы Приложения для диагностики ошибок.

Данные виджета OBS

Для показа виджета используется одноразовая ссылка с техническим ключом доступа; сообщения и события транслируются по ней в реальном времени в открытый источник «Браузер» OBS.

Приложение не собирает: пароли, платёжные данные, геоданные, контакты, файлы с устройства (кроме шрифтов и изображений, которые вы выбрали сами для виджета), рекламные идентификаторы, биометрию.

3.Данные Google и YouTube

Этот раздел подробно описывает работу Приложения с данными Google в соответствии с Условиями предоставления API Google (Google API Services User Data Policy).

Какие данные Google получаются

  • токен доступа OAuth учётной записи YouTube, подключённой автором канала;
  • идентификатор и название канала;
  • идентификатор активной трансляции и тексты сообщений её живого чата (live chat) — для отображения в ленте;
  • тексты сообщений, которые вы отправляете в чат через Приложение.

Для чего данные Google используются

Исключительно для работы функций Приложения: показ сообщений живого чата YouTube в ленте, отправка ваших сообщений и действия модерации через YouTube Data API. Данные Google не используются для рекламы, профилирования, автоматического принятия решений, обучения моделей и любых иных целей, не указанных в этом разделе.

Передача и ограничение использования

Данные Google не передаются третьим лицам, не продаются и не обмениваются. Единственные запросы с их участием — это обращения с вашего устройства к серверам Google, необходимые для работы YouTube Data API (Limited Use). Собственных серверов у Приложения нет.

Отзыв доступа и удаление

Отозвать доступ можно кнопкой «Выйти» в настройках Приложения либо в разрешениях аккаунта Google. После отзыва токен удаляется из локального хранилища Приложения. Полное удаление данных — удаление Приложения и папки %APPDATA%\MultiChat.

4.Как данные используются

Исключительно для работы Приложения:

  • приём и отображение сообщений подключённых чатов в единой ленте;
  • отправка ваших сообщений на выбранные платформы;
  • выполнение действий модерации (удаление сообщения, тайм-аут, бан, разбан);
  • отображение виджета и алертов событий в OBS;
  • корректный учёт лимитов запросов к API платформ;
  • сохранение ваших настроек между запусками.

Приложение не использует данные для рекламы, профилирования или автоматического принятия решений о пользователе. Приложение не использует API Google для создания или распространения несогласованных интимных изображений (AI NCII).

5.Сторонние сервисы и передача данных

Для выполнения функций Приложение обращается только к официальным API платформ:

  • Google / YouTube Data API — действуют условия Google: policies.google.com/terms, policies.google.com/privacy
  • Twitch / Amazon — действуют условия Twitch: twitch.tv/p/legal/terms-of-service
  • VK (VK Live API) — действуют условия VK: vk.com/dev/terms

Запросы отправляются напрямую с вашего устройства к серверам соответствующей платформы. Приложение не имеет собственных серверов и не пересылает ваши данные сторонним сервисам.

Приложение не содержит рекламных модулей, трекеров и аналитики; данные не продаются и не передаются третьим лицам в маркетинговых или иных целях, за исключением случаев, когда это необходимо для работы с официальными API указанных платформ или этого требует применимое законодательство.

6.Где хранятся данные

Все данные хранятся локально на вашем компьютере в системной папке %APPDATA%\MultiChat: конфигурационный файл с настройками и токенами, счётчики квоты, загруженные шрифты и изображения.

Приложение не загружает эти файлы на сторонние ресурсы; собственных серверов разработчика, куда передавались бы данные пользователей, не существует.

7.Сроки хранения и удаление данных

  • Токены доступа хранятся до отзыва вами (кнопка «Выйти») или до истечения срока действия.
  • История сообщений в ленте ведётся в оперативной памяти и не сохраняется между перезапусками Приложения.
  • Настройки и служебные данные хранятся до тех пор, пока Приложение установлено.

Полное удаление данных: удалите Приложение и папку %APPDATA%\MultiChat — все сохранённые данные будут удалены с устройства полностью. Отдельных аккаунтов и облачных хранилищ у Приложения нет.

8.Защита данных

Авторизация выполняется через официальные протоколы OAuth: Приложение не запрашивает и не хранит пароли аккаунтов. Токены и настройки хранятся только в локальной файловой системе вашего компьютера. Данные не покидают устройство за пределами необходимых запросов к API платформ.

9.Права пользователя

Вы вправе в любой момент:

  • отозвать доступ, нажав «Выйти» в настройках платформы;
  • отключить подключение отдельной платформы;
  • изменить или удалить любые сохранённые настройки;
  • полностью удалить данные, удалив Приложение и папку %APPDATA%\MultiChat;
  • запросить разъяснения о работе с данными по адресу Goddamn-Ravens@yandex.ru.

10.Изменения Политики

Политика может обновляться при изменении функций Приложения. Актуальная версия всегда опубликована по этому же адресу; дата последнего обновления указана в начале документа. Продолжение использования Приложения после изменения Политики означает согласие с её новой редакцией.

11.Контакты

По всем вопросам, связанным с конфиденциальностью и обработкой данных: Goddamn-Ravens@yandex.ru.
